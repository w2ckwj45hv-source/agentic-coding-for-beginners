# Request checklist

Before you send a request to an agent, check that it answers these four
questions. Thirty seconds here saves ten minutes of undoing.

| Question | Example |
|---|---|
| **Goal.** What should be true afterwards? | "Searching for `anna` should also find `Anna`." |
| **Place.** Where is it, as far as I know? | "Probably `find_student` in `search.py`." |
| **Limits.** What must it leave alone? | "Change only that function. Do not edit the tests. No new libraries." |
| **Done.** How will we both know it worked? | "Add a test with mixed case. All tests pass." |

## Before the session

- [ ] My work is committed.
- [ ] I can run the tests myself.
- [ ] My course allows this use.

## Before I accept a change

- [ ] I ran the tests in my own terminal.
- [ ] I read the whole diff.
- [ ] No test was weakened, skipped or deleted.
- [ ] Every changed line belongs to what I asked for.
- [ ] I can explain every line.

## Requests worth memorising

- "Explain this before changing anything."
- "Give me a plan. No edits yet."
- "Give me a hint, not the solution."
- "Change only this function."
- "Show me the real test output."
- "What is the simplest version that passes these tests?"
